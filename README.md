# BCFC Site
Plain HTML/CSS/JS site. Files: index.html (content), style.css (design), script.js (menu).
Deployed with Vercel from GitHub. Edit, commit, push -> the site updates automatically.


## Production URL

Use the project's production `*.vercel.app` URL as the public address for now. You can type or bookmark that address directly in Chrome; you do not need to open the Vercel dashboard.

Recommended routes:
- `/` — public BCFC website
- `/login` — BCFC Workers login

When a custom domain is purchased later, the same routes can be used on that domain.
